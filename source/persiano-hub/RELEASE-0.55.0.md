# Batchly 0.55.0

- Adds privacy-conscious trial activity monitoring with daily email summaries.
- Tracks login activity, Setup Wizard progress, relevant feature views, product changes, order creation and tester clarity feedback.
- Adds **Batchly → Trial Monitoring** settings and an on-site recent activity log.
- Excludes passwords, API credentials, payment data, customer message contents, phone numbers and addresses.
- Adds lightweight “Was this page clear?” feedback prompts.
- Repairs Hub access by refreshing rewrite rules after upgrades.
- Supports the front-end Hub through query-string URLs when WordPress uses Plain permalinks, avoiding `/hub/` server-level 404 errors.
