# Batchly 0.54.0

## Product rename
- Renamed the customer-facing product from Persiano Hub to Batchly.
- Updated admin menus, setup wizard, notices, emails, documentation and integration guidance.
- Preserved the existing `persiano-hub` plugin directory, PHP identifiers and stored option keys so existing installations upgrade without losing settings or data.

## Existing capabilities retained
- Business setup wizard
- Order correspondence timeline
- Rich payment-link email
- Two-way SMS and delivery statuses
- Square transaction tools
- Business profiles and white-label settings
- Manual-order defaults and automatic order-contact lookup
- GitHub update foundation
