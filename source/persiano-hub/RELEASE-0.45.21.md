# Batchly 0.45.21

## Label sheet wizard
- Format-first workflow retained.
- Avery sheet now uses a guided flow: choose unused positions, add/customize a product, store and add the next product, review, then generate.
- Every product group supports independent title, Persian title, description, ingredients, allergens, net quantity, dates, shelf life, batch, storage, preparation, custom notes, price, barcode/SKU, and QR destination overrides.
- Manual variants such as Vegetarian Olivieh can be printed without creating a separate WooCommerce product.

## Order documents
- New Batchly → Order Documents screen.
- Printable order summary for preparation/packing.
- Printable customer invoice.
- Invoice includes payment method, payment status, paid date, transaction ID, currency, addresses, line items, taxes, shipping, discounts, and order total.
- Paid online orders are clearly marked PAID.
- Print buttons are added to WooCommerce order screens and order actions.
