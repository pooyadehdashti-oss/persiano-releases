# Batchly 0.54.1

- Unified GitHub updater for both Batchly and Batchly Theme.
- One GitHub Release can update Persiano Dish, demo sites and future client sites.
- Required assets are `batchly-vX.Y.Z.zip` and `batchly-theme-vX.Y.Z.zip`.
- Preserves the legacy internal plugin folder `persiano-hub` for seamless upgrades.
- Targets the `batchly-theme` theme folder.
- Adds an opt-in automatic-update setting, enabled by default.
- Updates the included GitHub Actions release workflow.
