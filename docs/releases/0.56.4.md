# Batchly 0.56.4

## WordPress updater fix

- Uses GitHub's direct browser download URL for public release assets.
- Uses the authenticated GitHub API asset URL only when a private-repository token is configured.
- Validates authenticated downloads as ZIP files before handing them to WordPress.
- Replaces the unclear PclZip failure with a useful invalid-package error when GitHub returns HTML or JSON.
- Keeps the Batchly plugin-details modal, banner, icon, installation information and changelog integration.
- Continues the separate release model for Batchly Core and client-specific storefront themes.
