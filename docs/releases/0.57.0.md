# Batchly 0.57.0

## Google Reviews via Make.com

- Secure bearer-token webhook
- Single-review import
- Bulk historical-review import
- Google review ID deduplication
- Local WordPress review storage
- Publish, hide, feature and unfeature controls
- Reviewer name, photo, rating, comment and business reply
- `[batchly_reviews]` shortcode
- Grid and list layouts
- Minimum-rating and featured-only filters

### Endpoints

- `POST /wp-json/batchly/v1/google-reviews`
- `POST /wp-json/batchly/v1/google-reviews/bulk`
- `GET /wp-json/batchly/v1/google-reviews/status`
