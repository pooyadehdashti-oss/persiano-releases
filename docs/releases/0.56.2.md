# Batchly 0.56.2

## Update delivery and plugin details

- Added a canonical WordPress `Update URI` for Batchly.
- Improved the WordPress **View details** modal.
- Added description, installation instructions, changelog, homepage, icon and banner metadata.
- Uses the Batchly GitHub repository as the canonical plugin-information source.
- Added a GitHub Actions workflow to validate and publish Batchly plugin and theme ZIP packages.
- Includes the Manual Order and Food Label fixes from Batchly 0.56.1.

## Package requirements

The plugin release asset must be named:

`batchly-v0.56.2.zip`

and must contain the top-level folder:

`persiano-hub/`

The theme release asset remains:

`batchly-theme-v1.1.1.zip`

with the top-level folder:

`batchly-theme/`
